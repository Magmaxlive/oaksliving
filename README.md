# Font Files Required

To use the custom fonts (OptimaLTPro Roman and Graphik Regular), please add the following font files to this directory:

## Required Font Files:

### OptimaLTPro Roman (Title Font)
- `OptimaLTPro-Roman.woff2`
- `OptimaLTPro-Roman.woff`
- `OptimaLTPro-Roman.ttf`

### Graphik Regular (Body Font)
- `Graphik-Regular.woff2`
- `Graphik-Regular.woff`
- `Graphik-Regular.ttf`
- `Graphik-Medium.woff2`
- `Graphik-Medium.woff`
- `Graphik-Medium.ttf`
- `Graphik-Semibold.woff2`
- `Graphik-Semibold.woff`
- `Graphik-Semibold.ttf`

## Font Sources:
- **OptimaLTPro Roman**: Available from Adobe Fonts or Linotype
- **Graphik Regular**: Available from Commercial Type or Adobe Fonts

## Fallback Fonts:
If the custom fonts are not available, the website will fall back to:
- **Titles**: Optima LT Pro → Optima → Inter → System fonts
- **Body**: Inter → System fonts

## Usage:
The fonts are already configured in `fonts.css` and will automatically load when the font files are placed in this directory.
