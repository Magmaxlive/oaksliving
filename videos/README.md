# Video Files Required

## Hero Banner Video
- **File**: `oaks.mp4`
- **Location**: Place the video file in this directory
- **Specifications**:
  - **Format**: MP4 (H.264 codec recommended)
  - **Resolution**: 1920x1080 minimum (4K preferred)
  - **Duration**: 10-30 seconds (will loop automatically)
  - **File Size**: Under 10MB for optimal loading
  - **Aspect Ratio**: 16:9 recommended

## Video Content Guidelines
- **Style**: Luxury property showcase, architectural beauty
- **Mood**: Sophisticated, elegant, modern
- **Content**: Oaks Living properties, Auckland skyline, luxury living
- **Lighting**: Bright, natural lighting preferred
- **Movement**: Slow, cinematic camera movements

## Technical Requirements
- **Autoplay**: Video will autoplay on page load
- **Muted**: Video plays without sound (required for autoplay)
- **Loop**: Video loops continuously
- **Responsive**: Video scales to fit all screen sizes
- **Performance**: Optimized for web delivery

## Fallback
If the video fails to load, the hero section will display with a solid background color.
